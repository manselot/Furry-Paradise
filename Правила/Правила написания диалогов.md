# Правила написания диалогов

> [!abstract] Тема
> Человек без «данных» выигрывает головой и людьми.

1. **Держать голоса персонажей по досье.** Поступки не должны ломать ключевые принципы:
   - [[Гвен]] — без обмана;
   - [[Кортни]] — не врёт о потерях;
   - [[Кара Божья|Кара]] — не замечает критики.
2. **Только имена.** Персонажей называть по имени, без фамилий.
3. **Мир — через детали и реакции**, а не описания. См. [[Мир и премисса]].
4. **Каждый выбор игрока — с последствием** (переменная, ветка или реакция). Без фиктивных одинаковых опций.
