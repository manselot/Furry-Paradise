# Furry Paradise - Документация проекта

## Обзор проекта

**Furry Paradise** — интерактивная визуальная новелла / игра в виде сюжетной ВН с механиками квестов и диалогов.

**Жанр:** Романтическая фэнтези с элементами мистики

**Сеттинг:** Мир, где люди (Первородные) почти вымерли, а на их месте эволюционировали зверолюди. Главный герой — последний человек, скрывает свое происхождение, поступает в Академию Новой Эволюции среди студентов-зверолюдей.

---

```

├── персы/                          # Описания персонажей
├── Квесты/                         # Сюжетные квесты и цепочки
├── Диалоги/                        # Диалоговые деревья и сцены
├── Событие в сюжете/               # Ключевые события и сцены
├── История и строение мира/        # Лор, мировоустройство
├── гемплей и игра/                 # Механики, интерфейс, система
├── вступления.md                   # Глава 1 (текст)
├── вступления.yarn                 # Глава 1 (интерпретация для yarn)
└── .claude/                         # Конфигурация Claude Code
```

## Главные персонажи

### 🐕 Алина Волкова — Подруга детства
- **Вид:** Собака (золотистый ретривер)
- **Возраст:** 19 лет
- **Роль:** Best friend, романтический интерес, знает ГГ с детства
- **Черты:** Добрая, эмоциональная, заботливая, верная
- **Файл:** `[[персы/Алина Волкова подруга детства.md]]`

### 🐿️ Виктория Морозова — Спортсменка
- **Вид:** Белка (обыкновенная)
- **Возраст:** 20 лет
- **Роль:** Профессиональная спортсменка, одногруппница, виновница пропажи артефакта в квесте
- **Черты:** Дисциплина, упорство, молниеносная скорость, холодность (с мягким сердцем)
- **Квест:** Спортивная олимпиада (активируется после возврата артефакта) — дает баллы за участие
- **Файл:** `[[персы/Виктория Морозова отличница.md]]`

### 🐭 Мия Соколова — Мечтатель
- **Вид:** Мышь (полевая мышь)
- **Возраст:** 18 лет
- **Роль:** Художница, видит мир иначе, живет в фантазиях
- **Черты:** Творчество, чувствительность, наблюдательность
- **Файл:** `[[персы/Мия Соколова мечтатель.md]]`

### 🐻 София Романова — Королева университета
- **Вид:** Медведь (европейский бурый медведь)
- **Возраст:** 19 лет
- **Роль:** Популярная, харизматичная, скрывает одиночество
- **Черты:** Мощь, интуиция, способность быть защитнической
- **Файл:** `[[персы/София Романова.md]]`

### 👨 Алексей (ГГ) — Главный герой
- **Вид:** Человек (Первородный)
- **Цель внешняя:** Стать известным исследователем эволюции
- **Цель внутренняя:** Найти свое место в мире зверолюдей
- **Файл:** `[[персы/гг.md]]`

### 🐐 Кара Божья — Музыкант (сайд-персонаж)
- **Вид:** Козёл (горный козел)
- **Возраст:** 20 лет
- **Роль:** Комический персонаж, музыкант, источник побочных квестов
- **Черты:** Упорство, самоуверенность, отсутствие самокритики
- **Файл:** `[[персы/Кара Божья.md]]`

## Быстрый доступ

### Для писателя
- Обновить персонажа → `персы/[Имя].md`
- Добавить сцену → `Событие в сюжете/[Название].md`
- Добавить диалог → `Диалоги/[Название].md`
- Добавить квест → `Квесты/[Название].md`

### Для разработчика
- Изменить механики → `гемплей и игра/`
- Обновить лор → `История и строение мира/`
- Проверить сюжет → `[[Квесты/Сводка сюжета (для быстрого доступа).md]]`
